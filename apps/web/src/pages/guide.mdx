Everything you can do in the editor's ribbon you can also write as text. This page covers the
syntax, every option, and the export formats. Each figure here opens in the editor.

In the editor, click a layer (in the figure or the navigator) to select it: a **Layer** tab
appears in the ribbon with every setting of that layer, from its name and size to its kernel or
activation. Double-click a layer to open that tab. Rename the diagram by clicking its title at the
top, and write its description (the alt text) under File, Properties. On phones, tap a layer card
for the same settings.

## Shorthand

The quickest way to describe a network is one line of layer sizes:

```text
784-16-16-10
```

- Separate layers with `-`, a comma or spaces: `784, 128, 10` works too.
- Add an activation after a colon: `4-8:relu-3:softmax`.
- Repeat a layer with `*` and a count: `784-128*3-10` has three hidden layers of 128. This works
  for every layer type, like `conv(16,3x3):relu*2`.
- Repeat several layers together with parentheses: `in(28x28x1)-(conv(8,3x3)-pool(2))*2-flatten-fc(10)`
  has two convolution and pooling pairs. Groups can contain groups and repeats, like
  `(conv(32,3x3)*2-pool(2))*3`, and edits keep them.
- `dense(64)`, `fc(64)` and `linear(64)` all mean a fully connected layer of 64 neurons.
- Images, convolutions and pooling have their own words, like `in(28x28x1)-conv(8,3x3)-pool(2)`
  (see Convolutional networks).

<Figure id="g-shorthand" source="4-8:relu-3:softmax" caption="4-8:relu-3:softmax" />

The editor's shorthand bar (marked fx) shows the current network as shorthand. Typing there
changes sizes and activations and keeps every other setting, such as layer names.

## YAML and JSON

For names and options, write the network as YAML. A layer is either a number or a map of options:

```yaml
title: MNIST classifier
layers:
  - { units: 784, name: Pixels }
  - { units: 128, activation: relu }
  - 64
  - { units: 10, activation: softmax, name: Digits }
```

JSON works the same way, since every JSON document is also valid YAML. The model JSON export is
the canonical file format and opens again in the editor.

| Key           | Meaning                                                   |
| ------------- | --------------------------------------------------------- |
| `title`       | The figure's title, used as its accessible name.          |
| `description` | Alternative text. Without it, a description is generated. |
| `layers`      | The list of layers, input first.                          |
| `style`       | Options for the whole figure (see Styles and presets).    |
| `animation`   | How the figure moves (see Animation).                     |

Mistakes are reported with their line and column, and unknown keys suggest what you probably
meant. While the source has an error, the preview keeps the last valid figure.

## Layer options

These options are for fully connected (dense) layers, the default type. Convolutional layers
have their own, listed in the next section.

| Key          | Values             | Meaning                                                  |
| ------------ | ------------------ | -------------------------------------------------------- |
| `units`      | 1 to 1000000       | Number of neurons.                                       |
| `name`       | text               | Label under the layer. An empty name hides it.           |
| `activation` | a name like `relu` | Shown in the shorthand and the editor.                   |
| `collapse`   | `false`, or a map  | Per-layer collapse: `false` draws every neuron.          |
| `nodeLabel`  | text with `{i}`    | A label inside every neuron; `{i}` is the neuron number. |

Without a name, layers are called Input, Hidden (or Hidden 1, Hidden 2, ...) and Output.

### Large layers

Layers with more than 10 neurons are drawn as the first 3 and last 3 around an ellipsis. Change
the rule for one layer, or for the whole figure under `style`:

```yaml
layers:
  - { units: 64, collapse: { first: 2, last: 4 } }
  - { units: 20, collapse: false }
  - 12
style:
  collapse: { above: 16 }
```

Layers with more than 500 neurons are always collapsed. When two layers would need more than 2500
connection lines, they are drawn as one shaded band instead.

### Node labels

`nodeLabel` writes a label inside each neuron. `{i}` becomes the neuron's number, and the
numbering stays correct around the ellipsis.

## Convolutional networks

Start with an image, then add convolution and pooling layers. The size of every feature map is
worked out for you.

```text
in(28x28x1)-conv(8,3x3):relu-pool(2)-conv(16,3x3):relu-pool(2)-flatten-fc(64)-fc(10)
```

<Figure
  id="g-cnn"
  source="in(28x28x1)-conv(8,3x3):relu-pool(2)-conv(16,3x3):relu-pool(2)-flatten-fc(64)-fc(10)"
  caption="A small image classifier"
/>

| Shorthand             | Layer                                                              |
| --------------------- | ------------------------------------------------------------------ |
| `in(28x28x1)`         | An image: height, width and channels. `in(32x32)` has one channel. |
| `conv(16,3x3)`        | A convolution with 16 filters and a 3×3 kernel.                    |
| `conv(16,3,s2)`       | The same with a stride of 2. Add `valid` for no padding.           |
| `pool(2)`             | Max pooling over 2×2 windows. `avgpool(2)` averages instead.       |
| `pool(3,s2)`          | Pooling with a 3×3 window and a stride of 2. Add `same` to pad.    |
| `gap`                 | Global average pooling: one value per channel.                     |
| `flatten`             | Turns a feature map into a flat vector.                            |
| `fc(64)` or `64`      | A dense layer, as in fully connected networks.                     |
| `deconv(64,4x4,s2)`   | A transposed convolution: the map grows by the stride.             |
| `up(2)`               | Upsampling: every value repeats over a 2×2 block.                  |
| `reshape(4x4x512)`    | Turns a flat vector into a feature map.                            |
| `res(conv(16,3x3)*2)` | A residual block: its input is added to its output.                |

In YAML, give each layer a `type`:

```yaml
layers:
  - { type: input, shape: [28, 28, 1], name: Image }
  - { type: conv, filters: 8, kernel: 3, padding: valid, activation: relu }
  - { type: pool, size: 2, mode: avg }
  - { type: flatten }
  - { units: 10, activation: softmax, name: Digits }
```

| Key       | Layers                        | Meaning                                                                                        |
| --------- | ----------------------------- | ---------------------------------------------------------------------------------------------- |
| `type`    | all                           | `dense` (the default), `input`, `conv`, `pool`, `deconv`, `up`, `reshape`, `gap` or `flatten`. |
| `shape`   | input, reshape                | `[height, width]` or `[height, width, channels]`.                                              |
| `filters` | conv                          | Number of filters, which is the number of output channels.                                     |
| `kernel`  | conv                          | Window size: `3`, or `[3, 5]` for height and width.                                            |
| `size`    | pool                          | Window size, written the same way.                                                             |
| `stride`  | conv, pool                    | Step between windows. 1 for convolutions, the window size for pooling.                         |
| `padding` | conv, pool                    | `same` keeps the size (convolutions), `valid` adds none (pooling).                             |
| `mode`    | pool                          | `max` (the default) or `avg`.                                                                  |
| `shape`   | conv, pool                    | Draw the map at this size instead, like `26x26x8` (see below).                                 |
| `skip`    | dense, conv, pool, deconv, up | A skip connection, like `{ from: 2 }` (see below).                                             |

Every feature map is a stack of sheets, one per channel up to seven, with its size underneath
(28×28×8). Rays show the window each convolution or pooling step reads. The step itself is
written above it, like conv 3×3 or max 2×2; turn these off with the Operations switch or
`style: { labels: { ops: false } }` (Home tab, Labels group). Dense layers after the maps follow the preset: neurons and
connections, or bars with Layer boxes.

When a window does not fit its input, or a convolution follows a flat layer, the editor warns
you and still draws the figure.

To draw a map at another size than the one worked out, for example to match a paper, give the
layer a `shape` like `26x26x8` (or `26x26` to keep the channels), or type it in **Draw as** in the
Layer tab. The layers after it read that size, and the editor notes the difference.

### Skip connections

A residual block adds its input to its output, as in ResNet. Write the block's layers inside
`res( )`; repeats work as usual:

```text
in(32x32x3)-conv(16,3x3)-res(conv(16,3x3):relu*2)*2-gap-fc(10)
```

<Figure
  id="g-resnet"
  source="in(32x32x3)-conv(16,3x3)-res(conv(16,3x3):relu*2)*2-gap-fc(10)"
  caption="Residual blocks: each arc adds the block's input at the +"
/>

In YAML, a layer takes `skip: { from: 2 }`: the output of layer 2 joins this layer's output.
`op: concat` stacks the channels instead of adding them, as in U-Net. Shapes are checked at the
join, and the editor warns when they do not match. In the editor, select the layer and pick
**From** and **Join** in the Layer tab's Skip group. Adding, moving and removing layers keeps
every skip on the right layer.

When every skip stacks and they nest, each one reaching further out than the last, the network is
drawn as a U, like U-Net: the encoder goes down the left, the decoder comes back up the right, and
dashed bridges carry each skip across its row.

<Figure
  id="g-unet"
  source={`title: U-Net
layers:
  - { type: input, shape: [128, 128, 1], name: Image }
  - { type: conv, filters: 64, kernel: 3, activation: relu }
  - { type: pool, size: 2 }
  - { type: conv, filters: 128, kernel: 3, activation: relu }
  - { type: pool, size: 2 }
  - { type: conv, filters: 256, kernel: 3, activation: relu, name: Bottleneck }
  - { type: up, size: 2 }
  - { type: conv, filters: 128, kernel: 3, activation: relu, skip: { from: 4, op: concat } }
  - { type: up, size: 2 }
  - { type: conv, filters: 64, kernel: 3, activation: relu, skip: { from: 2, op: concat } }
  - { type: conv, filters: 2, kernel: 1, activation: softmax, name: Mask }
`}
  caption="A small U-Net: each bridge stacks an encoder level onto its decoder level"
/>

### Parameter counts

The **Parameters** switch (Home tab, Labels group) writes how many weights and biases each layer
learns under its size, like 100,480 params; pooling and flatten layers show a dash. In YAML:
`style: { labels: { params: true } }`. The status bar always shows the total, and the Layer tab
shows the selected layer's count. Counts follow the usual conventions: one bias per output, and
per gate for recurrent layers. Embeddings are not counted, because their size depends on the
vocabulary. Recurrent, Transformer, GAN and autoencoder figures do not draw the counts.

## Recurrent networks

Start with a sequence, then add recurrent layers. The network is unrolled over time: one cell per
step, the input below, the output on top and the state passed along. LSTM draws two state lines,
the cell state and the output.

```text
seq(20x32)-lstm(64)-fc(10):softmax
```

<Figure id="g-rnn" source="seq(20x32)-lstm(64)-fc(10):softmax" caption="An LSTM over 20 steps" />

| Shorthand        | Layer                                                         |
| ---------------- | ------------------------------------------------------------- |
| `seq(20x32)`     | A sequence of 20 steps with 32 numbers each.                  |
| `rnn(64)`        | A plain recurrent layer of 64 units.                          |
| `lstm(64)`       | An LSTM layer. `gru(64)` for a GRU.                           |
| `bilstm(64)`     | Reads the sequence both ways; drawn as two rows.              |
| `gru(64,last)`   | Passes on only the last step (many to one).                   |
| `tokens(50)`     | Text as 50 tokens, followed by `embed(128)` for word vectors. |
| `fc(10)` or `10` | A dense layer, applied at every step it receives.             |

Long sequences draw the first steps, an ellipsis and the last step; set how many with Steps
shown in the Network group of the Home tab, or `style: { steps: 6 }`. Two more switches sit
there: Neurons per step (`recurrent: neurons`) draws each step as a small network of neurons,
and Cell gates (`cell: true`) draws the gates inside one LSTM, GRU or RNN cell instead of the
whole network.

<Figure
  id="g-cell"
  source={'layers: seq(20x32)-lstm(64)-fc(10)\nstyle: { cell: true }'}
  caption="The gates of an LSTM cell"
/>

In YAML: `{ type: lstm, units: 64, bidirectional: true, last: true }` and
`{ type: sequence, steps: 20, features: 32 }`.

## Transformers

Transformers are drawn from left to right: tokens, the embedding with its positional encoding,
each stack of blocks in a frame with its count, and the head.

```text
tokens(1024)-embed(768)-decoder(12,12)-fc(50257):softmax
```

<Figure
  id="g-transformer"
  source="tokens(1024)-embed(768)-decoder(12,12)-fc(50257):softmax"
  caption="A decoder-only language model"
/>

| Shorthand           | Layer                                                           |
| ------------------- | --------------------------------------------------------------- |
| `tokens(512)`       | Text as 512 tokens. It comes first.                             |
| `embed(512)`        | Each token as 512 numbers, with positional encoding.            |
| `encoder(6,8)`      | Six encoder blocks with 8 attention heads.                      |
| `decoder(6,8,2048)` | Six decoder blocks; the third number is the feed-forward width. |

An encoder followed by a decoder gets two rows, the encoder on top, its output feeding the
decoder's cross attention. In YAML: `{ type: encoder, blocks: 6, heads: 8, ff: 2048 }`.

### Attention between tokens

**Token flow** on the Home tab (`style: { transformer: tokens }`) draws attention itself: one node
per token in the embedding and in each block (the first ones and the last), with a line from every
token a block reads, wider and darker for more attention. Decoder blocks only look back at earlier
tokens; encoder blocks read all of them. **Heat map** (`style: { transformer: heatmap }`) shows the
last block as a matrix instead. Give the words in the Tokens layer's **Words** field, or in YAML:

```yaml
style: { transformer: tokens }
tokens: [The, cat, sat, on, the, mat]
layers: 'tokens(1024)-embed(768)-decoder(12,12)-fc(50257):softmax'
```

<Figure
  id="g-tokens"
  source={`style: { transformer: tokens }
tokens: [The, cat, sat, on, the, mat]
layers: "tokens(1024)-embed(768)-decoder(12,12)-fc(50257):softmax"
`}
  caption="Token flow: each token attends to itself and earlier tokens"
/>

The weights are made up but repeatable: they show how attention works, not what a trained
model learned.

## GANs and autoencoders

A GAN holds two networks: the generator, from noise to a fake sample, and the discriminator, from
a sample to its score. Write them on either side of a bar.

```text
gan(100-256-512-784:tanh | 784-512-256-1:sigmoid)
```

<Figure
  id="g-gan"
  source="gan(100-256-512-784:tanh | 784-512-256-1:sigmoid)"
  caption="Generator and discriminator"
/>

Each network is a funnel with its neurons inside; Neurons in funnels on the Home tab (or
`style: { funnel: plain }`) shows only their names.

A convolutional GAN (DCGAN) uses feature maps inside the funnels. After the noise size, the
generator can reshape the noise into a small map and grow it with `deconv( )` or `up( )`; the
discriminator can start with an image and end with `flatten` and the score:

```text
gan(100-reshape(4x4x256)-deconv(128,4x4,s2):relu-deconv(64,4x4,s2):relu-deconv(3,4x4,s2):tanh | in(32x32x3)-conv(64,4x4,s2):relu-conv(128,4x4,s2):relu-flatten-1:sigmoid)
```

<Figure
  id="g-dcgan"
  source="gan(100-reshape(4x4x256)-deconv(128,4x4,s2):relu-deconv(64,4x4,s2):relu-deconv(3,4x4,s2):tanh | in(32x32x3)-conv(64,4x4,s2):relu-conv(128,4x4,s2):relu-flatten-1:sigmoid)"
  caption="A convolutional GAN: the generator's maps grow to an image"
/>

**Training arrows** on the Home tab (`style: { training: true }`) adds the losses under the
figure: dashed arrows from the score back to the discriminator, and on through it to the
generator.

An autoencoder narrows its input to a latent space and widens it back out. Write the encoder;
the decoder mirrors it, or give your own after a bar: `ae(784-256-32 | 32-128-784)`.
`vae(784-256-32)` draws a variational autoencoder, with a mean and a spread before the sampled
latent.

```text
ae(784-256-64-16)
```

<Figure id="g-ae" source="ae(784-256-64-16)" caption="An autoencoder" />

A plain network such as `8-4-2-4-8` can be drawn the same way: turn on Draw as autoencoder
(`style: { autoencoder: true }`), and its smallest layer becomes the latent space. In YAML:
`{ type: gan, generator: [100, 256, 784], discriminator: [784, 256, 1] }` and
`{ type: autoencoder, encoder: [784, 256, 32], vae: true }`.

## Styles and presets

A preset sets every color and shape at once. Pick one in the Design tab, or write it:

```yaml
style: { preset: colorblind }
```

| Preset            | Look                                                               |
| ----------------- | ------------------------------------------------------------------ |
| `classic`         | Light role tints: blue inputs, gray hidden layers, orange outputs. |
| `boxes`           | One bar per layer, its height growing with the layer's size.       |
| `mono`            | Gray levels only, for black and white printing.                    |
| `colorblind`      | The Okabe-Ito palette, safe for common color blindness.            |
| `colorblind-dark` | The same palette on a dark background, for slides.                 |

### Colors and outlines

To change colors, select a layer (in the figure or the navigator), then open **Fill** or
**Outline** in the Design tab. Colors belong to the kind of layer: input, hidden or output, so
every hidden layer shares one color. Hover a swatch to see it on the figure, click to keep it, or
open **More colors** to pick any color by hex, RGB or HSL. The Outline menu also sets the weight
(None hides the outline) and the dashes. Text inside nodes turns dark or white to stay readable.
Your colors stay when you switch presets; **Reset colors** brings back the preset's.

The selected layer gets a frame, and the other layers of its kind a lighter one, so you can see
which layers a color will change. On phones, select a layer card, then open Design in the
commands.

```yaml
style:
  hidden: { fill: '#e8f4ea', outline: '#009e73', weight: 2, dashes: dashed }
  output: { fill: '#1f2937' }
```

| Key       | Values                                    | Default      |
| --------- | ----------------------------------------- | ------------ |
| `fill`    | a quoted color                            | the preset's |
| `outline` | a quoted color                            | the preset's |
| `weight`  | 0 to 20 (outline width of a plain neuron) | 1.5          |
| `dashes`  | `solid`, `dashed`, `dotted` or `dash-dot` | `solid`      |

### Spacing

The Spacing group of the Design tab sets the layer gap, the node gap and the node radius, and
**Reset spacing** brings back the preset's. The layer gap is a minimum: long labels can push
layers further apart. The Design tab also holds **Transparent background** and **Right to left**.

Other style options:

| Key            | Values                          | Default         |
| -------------- | ------------------------------- | --------------- |
| `labels`       | `{ names, sizes, ops }`         | all shown       |
| `background`   | `transparent` or a quoted color | the preset's    |
| `nodeRadius`   | 2 to 100                        | 12 (CNN: 8)     |
| `nodeSpacing`  | 0 to 200                        | 9 (CNN: 5)      |
| `layerSpacing` | 20 to 2000                      | 110 (boxes: 96) |
| `direction`    | `ltr` or `rtl`                  | `ltr`           |
| `weights`      | `true` or `false`               | `false`         |

Write colors in quotes, like `background: '#ffffff'`, because YAML treats `#` as a comment.

`weights: true` draws every connection by a weight: blue for positive, vermillion for negative,
wider and darker for stronger ones. The weights are made up, not trained, and always the same
for the same diagram.

style: { weights: true }

## Animation

Open the Animate tab to see the figure move. Play and pause, step through it, or drag the slider
under the figure. There are five looks:

| Look       | What moves                                                                                  |
| ---------- | ------------------------------------------------------------------------------------------- |
| `pulse`    | Each layer lights up in turn, and the connections between layers flash.                     |
| `flow`     | Dashes run along the connections in the direction of the signal.                            |
| `dots`     | A dot travels along every connection.                                                       |
| `learning` | The weights drift from random to learned: color shows the sign, width the strength.         |
| `training` | Five examples in a loop: the signal goes forward, the error comes back, the weights change. |

Pulse, Flow and Dots show the forward pass in blue, backpropagation in vermillion, or both in
turn. Change both colors with **Forward** and **Backward** in the Animate tab. The settings are
saved with the diagram:

```yaml
animation: { look: training, speed: 0.5, grayHidden: true, forward: '#009e73' }
```

| Key          | Values                                          | Default      |
| ------------ | ----------------------------------------------- | ------------ |
| `look`       | `pulse`, `flow`, `dots`, `learning`, `training` | `pulse`      |
| `scene`      | `forward`, `backward` or `both`                 | `both`       |
| `speed`      | 0.25 to 4                                       | 1            |
| `loop`       | `true` or `false`                               | `true`       |
| `grayHidden` | `true` or `false`                               | `false`      |
| `forward`    | a quoted color                                  | the preset's |
| `backward`   | a quoted color                                  | the preset's |

With `grayHidden`, hidden layers keep their gray and only get a darker border when the signal
reaches them. Save the animation from the Animate tab:

- **Animated SVG:** plays anywhere an image does, in a README, a slide or a web page, with no
  scripts. Viewers who ask for reduced motion see the still figure.
- **GIF:** one loop at 12 frames per second, for slides and chats.
- **Video:** one loop at 30 frames per second, recorded in real time. WebM, or MP4 in browsers
  that only record that.

## Labels and math

Any name or node label can hold math between dollar signs. It is typeset with the New Computer
Modern font, like the math in a LaTeX paper, and mixes freely with text.

<Figure
  id="g-math"
  source={`layers:
  - { units: 784, name: '$\\mathbf{x} \\in \\mathbb{R}^{784}$' }
  - { units: 16, name: 'Hidden $h^{(1)}$' }
  - { units: 10, name: '$\\hat{\\mathbf{y}}$' }
`}
/>

- Write `\$` for a dollar sign that is not math.
- The TeX commands of LaTeX and the AMS packages work. Commands that load files or define
  macros do not.
- A formula with a mistake is shown as its source, with a warning that says what is wrong.

In YAML, put labels with backslashes in single quotes: `name: '$\alpha$'`. Inside double quotes,
backslashes must be doubled.

## Persian, Hebrew and CJK

Labels can use any of these scripts, and each label may mix them:

- Persian and Arabic with Vazirmatn, Hebrew with Noto Sans Hebrew.
- Chinese, Japanese and Korean with Noto Sans SC, JP and KR. A label with kana uses the Japanese
  forms, one with Hangul the Korean forms, and other Han text the Chinese forms.

The fonts load only when a label needs them. Each label reads in the direction of its first
letter, so a Persian name with a Latin word inside still reads right to left.

To mirror the whole figure, with the input on the right, turn on Right to left in the Design tab,
or set the flow direction:

  - { units: 64, name: لایه پنهان }
  - { units: 10, name: ارقام }

`}

## Exports

All exports are in the editor's Export tab, and on phones in the Export section of the commands.

| Format | Best for                       | Notes                                                   |
| ------ | ------------------------------ | ------------------------------------------------------- |
| SVG    | The web, Inkscape, Illustrator | Text outlined by default; see below for editable text.  |
| PNG    | Slides and documents           | 300 dpi by default; also 1x, 2x, 4x and 600 dpi.        |
| PDF    | Papers and print               | Vector, text outlined, one page the size of the figure. |
| TikZ   | LaTeX documents                | Code you can edit; see TikZ in LaTeX.                   |
| JSON   | Saving the model               | Opens again in the editor.                              |
| Embed  | Web pages and Markdown         | Markdown image, HTML image tag or data URL.             |

**Outlined or editable text.** Outlined text is drawn as shapes, so the figure looks the same in
every viewer and program. With Editable SVG text on, labels stay text you can change later, and
the fonts they use are embedded in the file (only the letters used, a few kilobytes).

**PNG resolution.** The resolution is saved in the file, so a 300 dpi PNG appears at the figure's
real size in Word, LaTeX and other programs.

**Accessibility.** Every SVG has a title and a description, taken from `title` and `description`
or generated from the layers.

## TikZ in LaTeX

The TikZ export rebuilds the figure as LaTeX code with every neuron as a named node, at exactly
the positions of the SVG. Choose the form in the Export tab:

- **Standalone document:** compiles on its own to a PDF of the figure.
- **Only the tikzpicture:** to paste into your paper. Its first lines say which packages it needs.

```latex
\documentclass{article}
\usepackage{tikz}
\usepackage{amsmath, amssymb} % only for math labels
\begin{document}
\begin{figure}
  \centering
  \resizebox{\linewidth}{!}{\input{network.tex}}
  \caption{Our network.}
\end{figure}
\end{document}
```

- Compile with pdfLaTeX, or with LuaLaTeX or XeLaTeX when labels use Persian, Hebrew or CJK
  text. Those labels use Vazirmatn, Noto Sans Hebrew or Noto Sans SC, JP or KR, the fonts the
  editor uses. Install them, or type another font in Export options. Right-to-left labels read
  correctly with both engines.
- Math labels stay LaTeX, so they match your paper. Other label text is escaped.
- Styles at the top, such as `xm input` and `xm edge`, control colors and line widths. Change one
  line to restyle every neuron of that kind.
- Coordinates are in px, with 1 px = 0.75 pt, as in the SVG.

## Command line

The repository also contains a command-line tool that renders the same files. From a copy of the
repository, after `pnpm install`:

```sh
node packages/cli/src/main.ts render network.yaml -o network.pdf
```

The output extension picks the format: `.svg`, `.png`, `.pdf`, `.tex` or `.json`. Other options:

| Option                    | Meaning                                      |
| ------------------------- | -------------------------------------------- |
| `-f`, `--format`          | Pick the format when writing to the console  |
| `--text live`             | Editable SVG text with embedded fonts        |
| `--no-embed`              | With `--text live`, name fonts, no embedding |
| `--dpi 600`               | PNG resolution (default 300)                 |
| `--tikz picture`          | Only the tikzpicture                         |
| `--tikz-font "B Nazanin"` | TikZ font for Persian, Hebrew or CJK labels  |
| `--prefix fig-`           | Prefix for ids in the SVG                    |

Use `-` instead of a file name to read from standard input, for example
`echo 784-16-10 | node packages/cli/src/main.ts render - > net.svg`.

## Keyboard shortcuts

On a Mac, use Cmd instead of Ctrl.

| Keys                         | Action                                                |
| ---------------------------- | ----------------------------------------------------- |
| Ctrl Z, Ctrl Shift Z, Ctrl Y | Undo and redo                                         |
| Ctrl S                       | Save now (every change is also saved by itself)       |
| Ctrl O                       | Open a diagram source file as a new document          |
| Ctrl E                       | Export again in the last format                       |
| Ctrl Enter or Insert         | Add a layer after the selected one                    |
| Alt Up, Alt Down             | Move the selected layer                               |
| Delete                       | Remove the selected layer                             |
| Escape                       | Close an open color menu, or select the whole diagram |

Delete, Escape and the layer keys work when the cursor is not in a text field. A double-click on a
layer opens its Layer tab.

## Sharing and privacy

- **Share links** carry the whole diagram after the `#` in the address. Browsers never send that
  part to any server, so the diagram reaches only the people you give the link to. A diagram too
  large for a link is saved as a file instead.
- **Your documents** are saved in this browser and stay on your device until you download your
  save file or turn on cloud save (see [Your profile](#your-profile)).
- Analytics run only if you accept them, and never see your diagrams. See
  [Privacy](../about/#privacy) on the About page.

## Your profile

There are no accounts. Your save is your key: one file with your diagrams, settings, name and
picture. The circle at the top right of every page opens [your profile](../user/).

- **Name and picture**: upload a photo, or pick an emoji or your initials on a color.
- **Your diagrams**: every diagram in this browser, as a grid, cards or a table. Sort or search
  them, and click one to open it in the editor. The … menu on each one renames, duplicates, marks
  a favorite (favorites stay on top) or deletes it.
- **Recently deleted** keeps deleted diagrams for 30 days, so you can restore them.
- **Export** downloads the diagrams shown as one ZIP file, in SVG, PNG, PDF, TikZ or source.
- **Defaults**: the style for new diagrams and the editor's export settings, saved with your
  diagrams so they follow you to other devices.
- **Cloud save**: connect Google Drive or Dropbox and your save updates by itself. Connect the same
  account on another device to bring everything there.
- **Save file**: download it, or open one; it joins what is already here, and the newer edit of
  each diagram wins.
- **Sign out** removes your diagrams, name and picture from this browser, for example on a shared
  computer.
